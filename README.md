# 莫高幻境 · 敦煌壁画数字漫游

一个面向手机的敦煌莫高窟数字展厅：**360° 洞窟漫游**、**双指放大看细节**、**即时配套语音讲解**、**矿物彩绘工坊**、微距壁画鉴赏与敦煌百科。

线上地址：<https://xingyudawang.github.io/>

---

## 这一版做了什么

这是对原 `library` 项目的重写，原先的三个主要问题都已在浏览器里实测修复：

| 原问题 | 现在 |
| --- | --- |
| 手机滑动、交互不佳 | 全局 `touch-action` 管理、真实 pointer capture、惯性、双击 / 双指手势、底部标签栏、安全区适配、44px 以上点击热区 |
| 绘画功能完全不可用 | 重写为图层化画布：Pointer Events + 压感、perfect-freehand 笔触、真实撤销 / 重做、可用的区域填色、印章、导出与收藏 |
| 360 全景只支持拖拽 | 真 3D 洞窟（四面墙 + 彩绘窟顶 + 中心塔柱），支持陀螺仪、双指缩放、光点锚定在墙面上，点开即朗读内置讲解词 |

### 关键实现

- **360° 洞窟**：不是把一张全景照片贴到球面上，而是按洞窟真实方位搭出房间——进入时面向西壁，左手南壁、右手北壁、背后东壁，窟顶单独一张彩绘。每一面墙都是该洞窟**那一面墙的真实扫描**，所以转身看到的确实是这座窟的北壁。
- **陀螺仪**：用 `alpha / beta / gamma` 构造完整四元数并补偿屏幕旋转方向，避免原实现里「一滚手机地平线就歪」的问题；无陀螺仪或权限被拒时会给出明确提示。
- **即时讲解**：讲解词随光点内置在数据里；`src/lib/narration.ts` 按标点切句排队朗读（绕过 Chrome 单条 ~15 秒截断），并把正在朗读的句子同步高亮成字幕。iOS 的权限请求在点击手势内触发。
- **绘制**：底稿是**真实壁画扫描的淡化版**（「等待上色的墙面」），而不是程序画出来的线稿；填充以底稿色调为边界，因此「点一下就涂满一块」是真的能用。
- **唯一的数字人**：讲解人「妙音」只有一个形象，头像取自第 57 窟南壁观音的面容（即「美人窟」得名的那张脸），只在讲解卡片出现。

## 图片来源

**本站所有壁画图片都来自敦煌研究院「数字敦煌」公开档案的真实扫描，没有使用 AI 生成图。**

具体做法：从数字敦煌的 Deep Zoom 瓦片金字塔（单幅最高 **59441 × 24152 px**）按需要的层级取瓦片、拼接、再转成 WebP。因此站点里的每一面墙、每一处「放大看细节」，都是原作的真实像素。

## 目录结构

```
.
├── index.html          # 构建产物（GitHub Pages 直接从这里提供服务）
├── assets/             # 构建产物：JS / CSS
├── media/              # 壁画与静态资源（唯一一份，供 app 构建时复制）
└── app/                # 源码
    ├── src/
    │   ├── components/ # 展厅、洞窟、鉴赏、工坊、百科、拼图、图鉴
    │   ├── data/       # 洞窟 / 壁画 / 讲解词 / 百科 / 题库
    │   ├── three/      # 360° 洞窟渲染引擎
    │   └── lib/        # 手势、朗读、绘画引擎等
    └── scripts/        # 取材与验证脚本（见下）
```

`media/` 只有一份：`app/vite.config.ts` 里一个很小的插件会在构建结束时把它复制到 `media/`，因此仓库里不需要出现两份 28 MB 的图片。

## 开发

```bash
cd app
pnpm install
pnpm dev        # http://127.0.0.1:5173
pnpm build      # 输出到仓库根目录所需的 .build-out/
pnpm typecheck
```

发布：`pnpm build` 之后，把 `.build-out/` 的内容覆盖到仓库根目录（`index.html`、`assets/`、`media/`），提交即可。GitHub Pages 设置为 **main 分支 / 根目录**。

## 取材与验证脚本（`app/scripts/`）

| 脚本 | 作用 |
| --- | --- |
| `collect-assets.mjs` | 抓取数字敦煌的洞窟清单、每面墙的标题与说明、Deep Zoom 源 |
| `fetch-assets.mjs` | 取瓦片、拼接、压成 WebP（`wall-* / ceiling-* / mural-* / detail-*`） |
| `derive-assets.mjs` | 从真实扫描里裁出百科配图、窟顶细节等 |
| `make-wash.mjs` | 生成彩绘工坊的「等待上色」底稿 |
| `make-guide.mjs` | 生成数字人妙音的圆形头像与个人印章徽记 |
| `verify.mjs` | 无头 Chrome 逐路由检查控制台报错与请求失败 |
| `shot.mjs` | 截图并统计亮度 / 方差 / 暖色占比，避免 WebGL 黑屏蒙混过关 |
| `touch-test.mjs` | 用真实触摸事件测试拖拽旋转、俯仰、双指缩放、绘制、撤销、填色 |
| `blender/floor.py` | Blender 无头脚本：烘焙洞窟沙地质感地面（`media/cave-floor.webp`） |
