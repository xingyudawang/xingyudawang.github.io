# 莫高幻境 · 敦煌壁画数字漫游

一个面向手机的敦煌莫高窟数字展厅：**360° 洞窟漫游**、**双指放大看细节**、**即时配套语音讲解**、**矿物彩绘工坊**、微距壁画鉴赏与敦煌百科。

线上地址：<https://xingyudawang.github.io/>

---

## 这一版做了什么

这是对原 `library` 项目的重写，原先的三个主要问题都已在浏览器里实测修复：

| 原问题 | 现在 |
| --- | --- |
| 手机滑动、交互不佳 | 全局 `touch-action` 管理、真实 pointer capture、惯性、双击 / 双指手势、底部标签栏、安全区适配、44px 以上点击热区 |
| 绘画功能完全不可用 | 重写为图层化画布：Pointer Events + 压感、perfect-freehand 笔触、真实撤销 / 重做、可用的区域填色、印章、导出与收藏 |
| 360 全景只支持拖拽 | 真 3D 洞窟（四面墙 + 彩绘窟顶 + 中心塔柱），支持陀螺仪、双指缩放、光点锚定在墙面上，点开即朗读内置讲解词 |

### 内容规模

- **15 个洞窟**：每个洞窟四面墙 + 窟顶都是该窟**那一面墙的真实扫描**，可 360° 环视
- **15 幅壁画**微距鉴赏：初始自动给到 1.75× 特写，可继续放大到 8× 拖到底部看细节
- **14 条敦煌百科**：颜料、乐器、纹样、工艺等条目，配图可双指放大，另嵌入 4 个 B 站科普视频
- **彩绘工坊**：10 幅整幅壁画底稿 + 拼图关卡 + 知识问答
- 底部导航 **6 个入口**：展厅 · 洞窟 · 鉴赏 · 绘制 · 百科 · 图鉴

### 关键实现

- **360° 洞窟**：不是把一张全景照片贴到球面上，而是按洞窟真实方位搭出房间——进入时面向西壁，左手南壁、右手北壁、背后东壁，窟顶单独一张彩绘。墙面纹理按相机朝向**渐进式加载**（640px 缩略图先出、转头时再取高清），首屏更快；个别偏暗的窟（如第 254 窟）做了整体增亮。
- **陀螺仪**：用 `alpha / beta / gamma` 构造完整四元数并补偿屏幕旋转方向，避免原实现里「一滚手机地平线就歪」的问题；无陀螺仪或权限被拒时会给出明确提示。
- **即时讲解**：66 条中文讲解音频随站点预先生成（微软 Edge TTS 神经语音，全端同一音色，句子边界带精确时间轴），点击光点即播；`src/lib/narration.ts` 优先播放预渲染音频，缺失时回退 Web Speech API 分句朗读（绕过 Chrome 单条 ~15 秒截断），字幕按句子边界同步高亮。英文界面暂不提供预生成音频，直接走浏览器语音合成回退。iOS 的权限请求在点击手势内触发；音色与语速偏好保存在本地。
- **微距鉴赏**：光点锚定在真实画面上，位置错了可以进入「校正点位」模式**直接拖动修正**（保存到本地）。底部信息栏可收起，不挡放大后的画面。
- **绘制**：底稿是把真实壁画做**四阶海报化**得到的「大色块填色图」（不再是一整张照片），点「填色」一下涂满一块，入门零门槛；画布支持**双指缩放 1–6 倍画局部细节**、双击切换、移动工具拖拽与一键复位。底稿是真实壁画的简化版，参考原画一键叠加对照。
- **数字人「九色鹿」**：全站只有一个数字人讲解员。讲解卡片里的头像取自第 257 窟西壁《九色鹿王本生》的**真实壁画裁切**；主页右下角漂浮的九色鹿吉祥物是**唯一一张 AI 生成图**（见「图片来源」）。语音优先使用神经网络音色（微软 Xiaoxiao / Google Wavenet 家族），按句换气、节奏舒缓。

## 图片来源

**壁画、墙面、窟顶图像全部来自敦煌研究院「数字敦煌」公开档案的真实扫描，没有使用 AI 生成图。**

具体做法：从数字敦煌的 Deep Zoom 瓦片金字塔（单幅最高 **59441 × 24152 px**）按需要的层级取瓦片、拼接、再转成 WebP。因此站点里的每一面墙、每一处「放大看细节」，都是原作的真实像素。

**唯一的例外**：主页右下角的九色鹿吉祥物（`deer-mascot.webp`）是应站主要求用 AI 图像 API 生成的，只作装饰形象；数字人讲解卡片的九色鹿头像仍是真实壁画裁切。

## 目录结构

```
.
├── index.html          # 构建产物（GitHub Pages 直接从这里提供服务）
├── assets/             # 构建产物：JS / CSS
├── media/              # 壁画与静态资源（唯一一份，供 app 构建时复制）
└── app/                # 源码
    ├── src/
    │   ├── components/ # 展厅、洞窟、鉴赏、工坊、百科、拼图、图鉴
    │   ├── data/       # 洞窟 / 壁画 / 讲解词 / 百科 / 题库
    │   ├── three/      # 360° 洞窟渲染引擎
    │   └── lib/        # 手势、朗读、绘画引擎等
    └── scripts/        # 取材与验证脚本（见下）
```

`media/` 只有一份：`app/vite.config.ts` 里一个很小的插件会在构建结束时把它复制到 `media/`，因此仓库里不需要出现两份 28 MB 的图片。

## 开发

```bash
cd app
pnpm install
pnpm dev        # http://127.0.0.1:5173
pnpm build      # 输出到仓库根目录所需的 .build-out/
pnpm typecheck
```

发布：`pnpm build` 之后，把 `.build-out/` 的内容覆盖到仓库根目录（`index.html`、`assets/`、`media/`），提交即可。GitHub Pages 设置为 **main 分支 / 根目录**。

## 取材与验证脚本（`app/scripts/`）

### 取材与图像处理

| 脚本 | 作用 |
| --- | --- |
| `collect-assets.mjs` | 抓取数字敦煌的洞窟清单、每面墙的标题与说明、Deep Zoom 源 |
| `collect-all.mjs` | 全量盘点：逐窟解析哪些墙面公开了高清瓦片金字塔 |
| `fetch-assets.mjs` | 取瓦片、拼接、压成 WebP（`wall-* / ceiling-* / mural-* / detail-*`） |
| `optimize-media.mjs` | 统一缩放 / 重压缩并生成 640px 缩略图（幂等、跳过锁定文件） |
| `fill-thumbs.mjs` | 只补缺失的 640px 缩略图 |
| `derive-assets.mjs` | 从真实扫描里裁出百科配图、窟顶细节等 |
| `make-wash.mjs` / `make-wash-new.mjs` | 生成彩绘工坊「等待上色」底稿（旧版与新增洞窟版） |
| `make-easy-bases.mjs` | 生成单主体裁剪的极简底稿（实验版，已弃用） |
| `restore-easy-bases.mjs` | 恢复 v2 整幅四阶海报化底稿——**当前工坊使用的版本** |
| `make-mascot.mjs` | 把 AI 生成的九色鹿吉祥物处理成圆形徽章 |
| `make-deer-avatar.mjs` | 从第 257 窟真实壁画裁出数字人九色鹿头像 |
| `make-guide.mjs` | 生成个人印章徽记（头像部分已由 `make-deer-avatar` 取代） |
| `make-encyc2.mjs` | 生成百科条目的裁切配图 |
| `fix-hotspots.mjs` | 按真实画面构图批量校正鉴赏页光点坐标 |
| `make-tts-narration.mjs` | 用微软 Edge TTS（免费神经语音、无需 API key）批量生成 66 条讲解音频，并生成 `ttsAudio.ts`（含句子级时间轴，供字幕同步） |
| `patch-perf.mjs` | 一次性性能补丁（提前隐藏加载遮罩等） |
| `blender/floor.py` | Blender 无头脚本：烘焙洞窟沙地质感地面（`media/cave-floor.webp`） |
